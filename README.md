# Pinche Club | Las Pinches Crepas 🥞✨

> **"El menú más chingón. Elige tu próximo antojo. Nosotros ponemos la crepa."**  
> *Hecho para los de buen antojo.*

Aplicación web moderna, responsiva y de alto impacto visual desarrollada en **React + Vite** con **Tailwind CSS** y **Lucide React** para el negocio real de comida street-gourmet **"Pinche Club | Las Pinches Crepas"**.

---

## 🚀 Características Principales

1. **Hero Section con Identidad de Marca:**
   - Estética nocturna *street-gourmet* (`#0B0D12` / `#141720`) con acentos dorados y chocolate.
   - Badge destacado: *"Servicio a domicilio los sábados de 7:00 p.m. a 10:30 p.m."*.
   - Botón directo de pedidos por WhatsApp y exploración rápida del catálogo.

2. **Catálogo y Explorador Inteligente de Menú:**
   - Buscador reactivo en tiempo real por nombre e ingredientes (ej. *pistache*, *Oreo*, *Philadelphia*, *salada*).
   - Filtro deslizable horizontal por categorías con contador dinámico de productos.
   - Menú completo con precios en MXN:
     - **Especialidades de $60 MXN:** *La Consentida, La Inolvidable, La Mamalona, La Untadita, etc.*
     - **Especialidades de $70 MXN:** *La Bien Encaprichada, La Pecadora, La Nigga, El Cusco, etc.*
     - **Las Más Pedidas:** *La Pinche Tentación, La Ya Valió Dieta, La Ex Tóxica, La Memela ($100), La Exagerada.*
     - **Especiales de la Casa:** *La Pinche Suprema, La Chingona, La Pinche Marranada ($250).*
     - **Crepas Saladas:** *Jamón con Queso, Dos Quesos, Pepperoni, Hawaiana, Omelette.*
     - **Bebidas & Frappés:** 11 sabores de Frappés y Malteadas, Bebida Rosada artesanal y Cafetería.
     - **Antojos & Snacks:** Plátanos fritos, papas gajo, alitas y boneless.

3. **Arma tu Crepa Dulce (Configurador Interactivo):**
   - Sistema dinámico para seleccionar untables (Nutella, Philadelphia, Cajeta, Pistache, etc.) y toppings (fresas, Kinder Bueno, Oreo, mazapán, etc.).
   - Cálculo automático del precio en tiempo real según la regla de negocio:
     - 1 Ingrediente: **$55 MXN**
     - 2 Ingredientes: **$60 MXN**
     - 3 Ingredientes: **$70 MXN**
     - 4 Ingredientes: **$80 MXN**
     - Ingredientes extras: **+$10 MXN** c/u (Kinder Bueno: **+$15 MXN** suplemento).
   - Generación de mensaje prellenado directo a WhatsApp con los ingredientes elegidos.

4. **Pinche Club (Ecosistema de Lealtad & PWA):**
   - Registro e inicio de sesión funcional simulado en `localStorage`.
   - Validación estricta de contraseñas de **mínimo 12 caracteres**.
   - Generación de **Código QR personal dinámico en SVG** para escanear en sucursal.
   - Catálogo de premios canjeables por puntos.
   - Guía interactiva de instalación PWA para **iOS (Safari)** y **Android (Chrome)**.

5. **Eventos & Barra Dulce:**
   - Cotizador instantáneo de barra dulce para eventos con enlace prellenado a WhatsApp.
   - Botón con copiado rápido del teléfono `(56) 4223 2061`.
   - Enlace oficial a Instagram (`@crepasest`).

6. **Footer Académico Institucional (CUCEI):**
   - Logo oficial de CUCEI – Universidad de Guadalajara.
   - Información de entrega académica completa (estudiante, materia, profesor y calendario 2026A).

## 💻 Instalación y Ejecución Local

Para correr el proyecto en tu máquina local:

```bash
# 1. Clonar el repositorio
git clone https://github.com/carlos7704/Negocio-Crepas.git

# 2. Entrar a la carpeta
cd Negocio-Crepas

# 3. Instalar dependencias
npm install

# 4. Iniciar servidor de desarrollo
npm run dev
```

Abre tu navegador en [http://localhost:5173/](http://localhost:5173/).
